## 📖 Overview

**Instagram Tool Care** is a desktop application designed to centralize multiple Instagram management and automation workflows into a single interface.

The project explores how **AI-assisted development (Vibe Coding)** can be used to transform product ideas and workflow requirements into a functional desktop application.

It combines account management, content workflows, scheduling, media management and automation tools in one application.

---

## ✨ Features

| Module | Description |
|---|---|
| 📊 **Dashboard** | Central overview of application activities |
| 👤 **Account Management** | Manage Instagram accounts |
| 📝 **Content Management** | Organize and manage content |
| 🎬 **Reels Management** | Manage Reel content and workflows |
| 📅 **Schedule Calendar** | Plan and manage scheduled activities |
| 🔄 **Account Care** | Support account-care automation workflows |
| 🔍 **Instagram Scraper** | Collect supported Instagram data |
| 🌐 **Proxy Management** | Configure and manage proxies |
| 🖼️ **Media Library** | Manage media assets |
| 🎨 **Image Editor** | Basic image editing tools |
| 🎞️ **Reel Editor** | Tools for preparing Reel content |
| ⚙️ **Settings** | Application configuration |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ndnvu2811/JS-IG.git
cd JS-IG
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development environment

```bash
npm run dev
```

### 4. Run the Electron application

```bash
npm run electron
```
